# sets

Implementation of the set type in the Go language

## Introduction

The module exports a generic type `Set[T comparable]`, which implements a set of type `T`, and a generic function
`New[T comparable]()`, which creates a set of type `T`.

All operations on sets are performed by calling `Set[T]` methods.

Sets are mutable, and most methods change the values of the sets on which they are called.

Set operations are implemented as methods that modify the set to which they are applied. Each method returns this
modified set, allowing for convenient computations to be implemented as call chains.

### Creating Sets and Manipulating Their Elements

`func New[T comparable]() Set[T]` creates and returns the empty set. The call `x := sets.New[type]()` is equivalent to
`x := make(sets.New[type])`

`func (s Set[T]) Values() []T` returns a slice containing all the elements of the set. It does not modify `s`.

| method                                      | descriprion                                                                                        |
|---------------------------------------------|----------------------------------------------------------------------------------------------------|
| (s Set[T]) Clone() Set[T]                   | A copy of the set s is created and returned. The maps.Сlone function is used. It does not modify s |
| (s Set[T]) Clear() Set[T]                   | Removes all elements from s and returns the new value s                                            |
| (s Set[T]) Add(v ...T) Set[T]               | Inserts values into s and returns a new value s                                                    |
| (s Set[T]) AddIter(q iter.Seq[T]) Set[T]    | Inserts the values generated by q into s and returns a new value s                                 |
| (s Set[T]) Remove(v ...T) Set[T]            | Removes values v from s and returns a new value s                                                  |
| (s Set[T]) RemoveIter(q iter.Seq[T]) Set[T] | Removes the values generated by v from s and returns the new value s                               |

### Predicates

These methods return a Boolean value and do not modify s or w.

| method                           | mathematical  | description                          |
|----------------------------------|---------------|--------------------------------------|
| (s Set[T]) Equal(w Set[T]) bool  | s = w         | the sets s and w are equal           |
| (s Set[T]) Subset(w Set[T]) bool | s ⊆ w         | s is a subset of w                   |
| (s Set[T]) In(v T) bool          | v ∈ s         | v is in s                            |
| (s Set[T]) Any(v ...T) bool      | ∃x ∈ v: x ∈ s | s contains at least one value from v |
| (s Set[T]) All(v ...T) bool      | ∀x ∈ v: x ∈ s | s contains all the values in v       |

### Set Operations

These methods do not modify w, but modify s and return the new value s.

| method                               | mathematical | description                         |
|--------------------------------------|--------------|-------------------------------------|
| (s Set[T])Union(w Set[T]) Set[T]     | s ← s ∪ w    | The union of s and w                |
| (s Set[T])Intersect(w Set[T]) Set[T] | s ← s ∩ w    | The intersection of s and w         |
| (s Set[T])Diff(w Set[T]) Set[T]      | s ← s ∖ w    | The set difference of s and w       |
| (s Set[T])SymDiff(w Set[T]) Set[T]   | s ← s ∆ w    | The symmetric difference of s and w |

## Implementation Features

A very simple generic set type, based on map\[comparable\]struct{}. It includes basic mathematical operations on sets
and set conversions to and from JSON and YAML.

The methods implementing set operations and working with JSON use only the standard library. However, working with YAML
requires a third-party library.
